# Manual del participante — Clase 1

## Preparación

Sigue el [`README.md`](../README.md) y [`AZURE_SETUP.md`](AZURE_SETUP.md) si tienes tu propia suscripción de Azure. 

Usa esta guía como hoja de actividades.

## Ejercicio 1 — Prompt inicial 

1. Selecciona **01 · Prompt inicial**.
2. Lee las instrucciones y el mensaje del cliente.
3. Pulsa **Ejecutar ejercicio**.
4. Identifica si el asistente inventa el estado del envío o propone acciones no respaldadas por un sistema real.

**Pregunta:** ¿Qué información falta para contestar correctamente al cliente?

## Ejercicio 2 — Prompt mejorado 

1. Selecciona **02 · Prompt mejorado**.
2. Compara las instrucciones con las del ejercicio 1.
3. Ejecuta y revisa tono, longitud, estructura y conformidad con la política.
4. En modo instructor, modifica una condición y vuelve a ejecutar.

**Pregunta:** ¿Basta con pedir "no inventar" para garantizar exactitud?

## Ejercicio 3 — Clasificación y JSON 

1. Selecciona **03 · Clasificación y JSON**.
2. Ejecuta y observa el resultado y la validación local.
3. Revisa categoría, prioridad, resumen y revisión humana.
4. Discute cómo utilizarías esa salida en un sistema de tickets.

**Pregunta:** ¿Qué validaciones adicionales necesitaría una aplicación de producción?

## Ejercicio 4 — Conocimiento limitado 

1. Selecciona **04 · Conocimiento limitado**.
2. Observa qué preguntas están respondidas explícitamente en el texto de política.
3. Ejecuta y comprueba si el modelo admite cuando falta información.

**Pregunta:** ¿Qué fuente corporativa necesitarías conectar para conocer el estado real del pedido?

Si el botón **Continuar respuesta anterior** es compatible con tu implementación, ejecuta un seguimiento. Descarga los resultados JSON y compara respuestas.
